## What belongs here

A single connection diagram showing the STM32, BTS7960 + motor, the servo, the BNO085, the
TCA9548A multiplexer with its ToF sensors and the TCS34725, the encoder, the Raspberry Pi 5 +
camera + RPLIDAR C1, and the four power rails meeting at one star ground. Export as PNG or PDF so
it renders on GitHub and prints cleanly.

Keep the diagram in agreement with [`../electrical/README.md`](../electrical/README.md) and
[`../SPECSHEET.md`](../SPECSHEET.md) - if a pin moves, update all three.
